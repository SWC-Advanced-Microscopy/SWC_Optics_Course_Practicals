# Parts Lists

This document describes the parts used to run the SWC optics course. This list was originally made in 2020 and now slightly out of date. We have added some parts and not all parts are now stored in boxes. Nonetheless, it serves as good guide for what is needed to run the course. Another parts list, which may be more up to date, is [at this GDrive link](https://docs.google.com/spreadsheets/d/1is80vgazc9cKmk0LXUsbfMXYhyRgAPzeTvZJaSML3Yk/edit?usp=sharing).

### BOX: Galvo control cards

This box contains galvo control cards for the. The cards are paired with a specific scanner. Plug the X control card into the X galvo.

### BOX: PMT

Each group is provided with a PMT and a PMT power supply. The Red and Green groups have a small PMT and a black PSU with a potentiometer for adjusting PMT gain. The blue group has a larger PMT which is powered via an AC/DC wall adapter. The gain on this unit is set via an analog input. A small USB DAQ is supplied for this purpose.
CARE: PMTs can be damaged by exposure to bright light when they are powered on. Do not turn on the room lights or use a flash light in the vicinity of an energised PMT. Ensure potentially bright samples (such [Chroma test slides](https://www.chroma.com/products/accessories/92001-autofluorescent-plastic-slides)) are dim before turning on the PMT.
